# Max Speed (Balanced) - Raised XY Motion and Faster Tool Changes
# Origin: https://github.com/JNP-1/Snapmaker-U1-Config, reduced here. The
# conservative tier; tool change values sit at roughly half the point where tool
# confirmation retries were observed.
#
