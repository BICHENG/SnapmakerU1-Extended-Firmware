# EPIC-G — Report and handoff

## Goal

Leave a reproducible engineering record and a clear rollback path.

## Report sections

1. Scope and exact firmware/build identity.
2. Baseline versus post-upgrade configuration.
3. Fan curve definitions and runtime semantics.
4. IMU method, raw-data index, derived metrics, and repeat counts.
5. Service/Tailscale checks.
6. Results, limitations, and claims marked VERIFIED, INCONCLUSIVE, or NOT VERIFIED.
7. Rollback commands and backup locations.

## Handoff gate

The report is not complete until every claim points to a saved artifact or command output.
